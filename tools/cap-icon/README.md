# App icon

The Counterball icon is a real 3D crown cap rendered with three.js (`index.html`).

To re-render: link `three` next to the page (`ln -s ../../node_modules/three three`),
serve this folder (`python3 -m http.server 8811`), open
`http://127.0.0.1:8811/index.html?el=58&d=5.2` and screenshot at 1024×1024
(`d=6.3` gives the zoomed-out maskable version). Paint colour: `&paint=%231638b8`.
